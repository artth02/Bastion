01

Running Bastion

With Docker

Requires Docker and docker-compose. The compose file starts four workers with the API on 10007 and Socket.IO on 10008.

terminal
docker-compose up

By hand

Requires Node.js 14.2+ and npm 6.14+.

terminal
npm install
npm start

03 · Web and Cordova apps

Connecting

Load the Socket.IO client that Bastion serves on its IO port. The path is always the one below unless you change Bastion's code.

index.html
<script src="http://bastionHost:10008/socket.io/socket.io.js"></script>

Then connect to the /bastion/notification namespace. A connect event means you're in.

app.js
// host:socket-io-port/bastion-namespace
window.socket = io.connect('http://bastionHost:10008/bastion/notification')

socket.on('connect', () => {
  // connected
})

04

Joining channels

Emit bastion-join with a custom id (any id that means something to you, like a user id) followed by one or more channel names.

app.js
socket.on('connect', () => {
  socket.emit('bastion-join', { customId: id }, 'channel-name')
})

05

Messaging

A Bastion message has two parts. meta tells Bastion where it goes. notification is what you send: an object, array, string or number. Bastion never looks inside it.

message
{
  meta: {
    channels: ['index', 'channel1']  // who receives it
  },
  notification: {}                   // anything you like
}

From a socket there are two ways to send:

EventDelivers to
bastion-emit-notificationEvery socket in the channel, including the sender
bastion-broadcast-notificationEvery socket in the channel except the sender
app.js
// broadcast
socket.emit('bastion-broadcast-notification', message, 'receiving channel')

// emit
socket.emit('bastion-emit-notification', message, 'receiving channel')

06

Receiving

Whatever the source (a socket emit, a broadcast or an HTTP POST), listeners get a bastion-notification event carrying the notification value.

app.js
socket.on('bastion-notification', (notification) => {
  // your code here
})

07

HTTP API

Served on the API port (10007 by default), not the Socket.IO port.

POST /bastion/notification

Sends a message to any of Bastion's channels. The body is the same structure as in Messaging.

request body
{
  "meta": { "channels": ["index", "channel1"] },
  "notification": {}
}

GET /bastion/inspect/channels

Lists the open channels and how many sockets are in each.

GET /bastion/inspect/channels/{channelName}

Lists the sockets in one channel, with their socket id and custom id.

GET /bastion/healthcheck/ping

Liveness check for load balancers and orchestrators.

08

Responses

Success

200 OK or 204 No Content, with an empty body.

Errors

Errors share one shape. The default messages are in Portuguese.

404
{
  "developerMessage": "A operação solicitada não foi encontrada",
  "userMessageTranslated": "Não foi possivel concluir a operação solicitada",
  "errorCode": 404,
  "moreInfo": {
    "developerMessage": "Recurso não encontrado",
    "message": "A operação solicitada não foi encontrada",
    "status": 404
  }
}
